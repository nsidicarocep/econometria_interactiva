Inferencia Estadística en Regresión

Un laboratorio interactivo para explorar varianza de estimadores, tests t, intervalos de confianza y comparación de modelos

Bajo los supuestos del Modelo Lineal Clásico (MLR.1–MLR.6), los estimadores OLS tienen distribución normal. Esto permite construir tests de hipótesis e intervalos de confianza. En esta página vas a poder experimentar con cada pieza del proceso de inferencia.

1. Varianza de los Estimadores MCO

Bajo los supuestos CLM, la varianza del estimador β̂j depende de tres factores:

Var(β̂j) = σ²STCj · (1 − R²j)

Donde σ² es la varianza del error, STCj = Σ(xji − x̄j)² es la variación total de xj, y R²j mide la colinealidad con los demás regresores. En regresión simple (R²j = 0):

Var(β̂1) = σ²Σ(xi − x̄)² = σ²n · Var(x)

Tres palancas determinan la precisión: más dispersión en x, menor varianza del error y mayor tamaño de muestra producen estimaciones más precisas.

2. Error Estándar y Test t

Para testear H0: βj = 0 contra H1: βj ≠ 0, construimos el estadístico t:

tβ̂j = β̂jse(β̂j)  ∼  tn−k−1   bajo H0

El estadístico t mide cuántos errores estándar está β̂j alejado de cero. Si |t| es grande, tenemos evidencia para rechazar H0. Generá muestras individuales y observá cómo varía el resultado entre una muestra y otra.

3. Intervalos de Confianza

Un intervalo de confianza al (1−α)×100% para βj es:

IC = [β̂j − cα/2 · se(β̂j),   β̂j + cα/2 · se(β̂j)]

La interpretación correcta: si repitiéramos el muestreo muchas veces, el 95% de los intervalos construidos de esta forma contendrían al verdadero βj. El parámetro es fijo; lo que varía es el intervalo.

4. Potencia: ¿"no significativo" = efecto nulo?

Error frecuente: "No rechazar H0" NO implica que βj = 0. Solo significa que no tenemos suficiente evidencia para descartarlo con los datos disponibles.

La potencia del test es la probabilidad de rechazar H0 cuando es falsa (es decir, cuando el efecto realmente existe). Depende de tres factores: el tamaño del efecto (β1), la varianza del error (σ²) y el tamaño de muestra (n).

Clave: si β1 = 0.5, σ = 4 y n = 30, la potencia es muy baja. Esto significa que en la mayoría de las muestras no detectamos el efecto aunque es real. Aumentá n a 200 para ver cómo la potencia crece. "No significativo" puede simplemente indicar muestra insuficiente.

Significativo ≠ importante

Con n suficientemente grande, cualquier efecto, por minúsculo que sea, será significativo. Bajá β1 a 0.1 y subí n a 300: el test rechazará frecuentemente, aunque el efecto práctico sea despreciable. Siempre hay que mirar el tamaño del coeficiente, no solo su significatividad.
