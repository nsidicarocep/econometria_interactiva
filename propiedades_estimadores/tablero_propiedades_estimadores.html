Propiedades de los Estimadores

Un laboratorio interactivo para explorar insesgadez, eficiencia, consistencia y el trade-off sesgo-varianza

Un estimador es una fórmula que aplicamos a una muestra para aproximar un parámetro poblacional desconocido. Como cada muestra es distinta, el estimador es una variable aleatoria. En esta página vas a poder generar datos, simular miles de muestras y ver con tus propios ojos qué hace "bueno" o "malo" a un estimador.

1. Distribución Muestral

2. Insesgadez (ausencia de sesgo)

Un estimador θ̂ es insesgado si su valor esperado coincide con el parámetro:

E[θ̂] = θ   ⇒   Sesgo(θ̂) = E[θ̂] − θ = 0

Comparemos un estimador insesgado (la media muestral) con uno al que le sumamos una constante (sesgo controlable). Ambos estiman μ = 10.

3. Eficiencia

Entre dos estimadores insesgados, preferimos el de menor varianza. Un estimador más eficiente produce estimaciones más concentradas alrededor del valor verdadero.

Var(θ̂1) < Var(θ̂2)  ⇒  θ̂1 es más eficiente

Comparemos la media muestral (eficiente) con la mediana muestral y con el primer valor X1. Los tres son insesgados para datos normales simétricos, pero tienen varianzas muy diferentes.

4. Consistencia

Un estimador es consistente si converge en probabilidad al valor verdadero cuando n → ∞:

θ̂n ⟶ θ  cuando  n → ∞

Intuitivamente: con más datos, el estimador se acerca cada vez más al parámetro. Mové el slider para ver cómo la distribución se "aprieta" al aumentar n.

5. Trade-off Sesgo-Varianza

No siempre el mejor estimador es el insesgado. El Error Cuadrático Medio (ECM) captura ambas dimensiones:

ECM(θ̂) = Var(θ̂) + [Sesgo(θ̂)]²

Un estimador con un poco de sesgo pero mucha menos varianza puede tener un ECM menor.

El desvío muestral: sesgado por Jensen

Aunque s² = Σ(Xi−X̄)²/(n−1) es insesgado para σ², su raíz cuadrada s = √s² no es insesgada para σ. Esto es consecuencia de la desigualdad de Jensen: para una función cóncava como la raíz cuadrada, E[√X] ≤ √E[X].
